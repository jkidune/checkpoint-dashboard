# Checkpoint portfolio asset capture

Captures use actual Checkpoint React/Astro screens with **fictional** contribution, equity, loan, and member records. The screenshots are design-review assets, not evidence of real customer results. No production API, database, payment details, passwords, or customer records are accessed. Non-GET API calls are blocked.

The Checkpoint product is financial management for VICOBA / investment clubs. Its official blue, mint, and teal brand is stored under `frontend/public/brand/`. Earlier orange legal/inspection concept boards are unrelated and must not be published as the Checkpoint case study.

The GitHub Actions workflow generates an artifact called `checkpoint-portfolio-screens` with a 14-day retention period. Nothing is merged into the production app or pushed to Barons Digital or Sanity automatically.
